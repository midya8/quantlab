Limits and provenance
2..8 rows, 1..128 features, finite magnitudes ≤ 1,000,000. Every product has magnitude ≤ 16,129 and every prefix ≤ n × 16,129 ≤ 2,064,512, well within signed int32. Python integers are unbounded; browser Numbers represent these bounded integers exactly. This is a checked bound, not a hardware int32 benchmark. Bias, asymmetric zero-points, output requantization and integer-only nonlinearities are not implemented.
Exact fractions describe the real linear maps of the represented binary64 inputs and stored IEEE scales. Runtime rescale and exact-real predictions are separate; first row wins ties. The activation range is supplied by the user, not calibrated or optimized on held-out data. Constructed controls are arithmetic examples, not trained results. Original QLB1 files and trained fixtures are unchanged.
Jacob et al.: quantized integer inference establishes the broader method, including the fixed-point output steps this page does not implement. ONNX rounding context, not ONNX compatibility. Python Fraction and independent browser BigInt dyadics supply exact witnesses. No new quantization algorithm is claimed.
