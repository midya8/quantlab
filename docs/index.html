02 / THE CONTAINER

Count the file, not the promise.

The original experiment's fp32 byte counts are conceptual. Its Python weights and inference use binary64. QLB1 stores actual signed bytes and either 32-bit or 64-bit scales. Changing scale precision keeps the original integer codes and rounds only the metadata, not a new quantizer.

24-byte little-endian header → IEEE scales → row-major int8 codes → 4-byte CRC32. CRC32 detects accidental corruption; anyone can recompute it. It is not a signature or authentication.

A margin is not an accuracy claim.

What this leaves out.
The format stores a finite matrix, not a complete model. It excludes biases, vocabulary, feature extraction, labels, activations and framework metadata. Exported bytes are real; an in-memory browser array is not an int8 RAM benchmark. No wall-clock or hardware speedup is measured.
The original synthetic topic classifier uses hashed bag-of-words counts and perceptron updates. Token order is discarded and hash collisions are possible. Unchanged fixture accuracy is not evidence of parity on transformers or unseen tasks.
Symmetric absmax quantization, ties-to-even rounding and elementary linear error bounds are standard methods, not new algorithms. QLB1 is a small educational format, not ONNX, GGUF or a secure artifact format.
